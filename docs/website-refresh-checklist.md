# Website refresh checklist

Standing user preference: retain the full visual single-page homepage restored on
14 November 2026. Content updates must not reinstate the rejected short overview.
Keep the Forbes hero, compact experience grid and large visual sections.

For every requested update:

1. Read AGENTS.md, the latest coverage report, source registry and current content.
   Reconcile any supplied CV, retaining substantive historical records and details.
2. Review full accessible LinkedIn posts/articles and Bluesky author posts since
   the previous audit, with an overlap. Follow feed pagination where necessary.
   Inspect both image arrays and multi-image gallery attachments, plus external
   links and quoted-post context. Verify that the post is Joyjit's own account.
3. Search name variants and relevant exact work titles across university and
   employer news, organiser pages, industry publications, professional societies,
   LinkedIn organisation mentions, Facebook, X, YouTube, interviews and podcasts.
   Check Hull, Loughborough/LDR and other known institutions for updates.
4. Reconcile LDR, publisher/DOI records, ResearchGate and Google Scholar. Search for
   independent citations in teaching, doctoral guidance, reviews, new research,
   professional reports and industry discussions. Citation alone is not adoption.
   Store only PDFs suitable for redistribution and maintain source/licence records.
5. Check announced events for completion and awards for new outcomes. Preserve
   speaker/panellist/guest/attendee and finalist/winner distinctions. Recognise
   collaboration and senior stakeholder engagement without invented titles.
6. For each new event, inspect every available attached photograph and select
   useful originals. Download local assets, record dimensions, source post, source
   image URL, dates, caption and alt text. Show a suitable image with the event on
   the homepage. Group related photos under one shared event title and caption,
   selecting a lead and supporting images instead of duplicate event cards. Avoid
   repeating the same event across prominent sections. Keep access to the full
   post and remaining photographs. Do not
   substitute generic images or treat search thumbnails as a full post review.
7. Preserve anonymous role-only feedback, the financial evaluation basis, exact
   credentials, publication authorship and all prior source corrections. Avoid
   em dashes and job-seeking language. Keep technical detail in disclosures.
8. Update a dated report: channels/search scope, full posts reviewed, number of
   attachments reviewed/selected, additions, already-covered material and gaps.
   Mark gated/unavailable feeds explicitly. Never call a sampled search exhaustive
   or claim that all internet mentions have been found.
9. Build and check the homepage, research/profile pages, compatibility routes,
   visible image references, links, mobile styles and interactions. Use connected
   browser QA when available, and state when unavailable. Publish and verify the
   actual live release when authorised, as in this ongoing website task.

This is a workflow triggered by update requests, not an automatic scheduled job.
